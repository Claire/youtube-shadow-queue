Sort a big queue into smaller ones

  1. In YouTube, open the Queue panel and click Backup.
  2. In the repo folder run node tools/enrich.mjs ~/Downloads/youtube-queue-backup-….json.
  3. Click Open enriched.json… above (it's in the repo's data folder), or drop the file on this page.

Nothing is uploaded. This page only loads video pictures from YouTube, and you can turn those off.
